\section*{Use of large language models}
This project was carried out with extensive use of an LLM-based coding agent (Claude, Anthropic, used through Claude Code).
Under the authors' direction the agent wrote and tested the reference implementations, validation and mutation tests, the
map and analysis code, the pre-registration and specification drafts, the build pipeline that re-extracts every number in
this paper from pinned result files, literature searches (each citation checked against its primary record), and drafts of
the text. The authors set the research questions, approved every pre-registration, freeze, amendment and analysis decision at
recorded checkpoints, ran or authorised all compute, and read the final text and checked the main claims against the
claims-to-evidence table. The internal reviews used during the work, including the hostile reviews, were performed by separate
LLM agent instances and are not peer reviews. Every decision, failure and correction is recorded in append-only disclosure
logs released with the code (anonymised for review). The authors take full responsibility for the content.
