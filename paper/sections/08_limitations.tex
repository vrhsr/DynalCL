\section{Limitations}\label{sec:limits}
\begin{itemize}
\item \textbf{One prior, one comparator per family.} Every map uses a single population prior and a single context-only
comparator. The gaps depend on both: a more concentrated population prior, a vaguer or sharper context-only noise prior in
F1, or a different comparator (least squares plug-in, a scale-agnostic prior in the known-scale family) would move the
windows. We have not mapped this dependence; the F1 window in particular may partly reflect how vague the context-only noise
prior is.
\item \textbf{Margin.} The window depends on $\delta$ (Table~\ref{tab:delta}); $\delta$ was fixed in advance as a small
log-score difference, not derived from the seed variance of trained models.
\item \textbf{Power.} The F3 map is underpowered at moderate noise; its estimator could be replaced by a Rao--Blackwellised
one, as in the 1A map, or its sample size increased.
\item \textbf{Per-cell rules and dependence.} The maps use per-cell rules without a global correction and common random
numbers, so a few cells per map may be mis-marked by chance and patterns across cells are descriptive. Pooled tests could
separate references in cells where each per-cell gap is below $\delta$.
\item \textbf{Designed sets.} Where library and continuous references separate on probe or out-of-support sets, the gap is
not a divergence and partly reflects how well the library covers the edge of the stable region.
\item \textbf{Simple families.} All results concern linear autoregressive processes with Gaussian noise, scalar or
bivariate; nothing is claimed for nonlinear, chaotic or high-dimensional systems. Each confirmatory study ran on one platform
with two replicates.
\item \textbf{Monte Carlo limits in F2.} The bivariate context-only reference is not computable to our criterion at the
shortest contexts, so the F2 population window is not mapped there. Because the cell-level Monte Carlo criterion tightens as
the number of evaluation items falls, several in-library F2 cells with fewer items are also \textsc{mc-limited}; the sample
sizes were fixed before this was seen. The explanation offered for the bivariate library result (sparse coverage of a
four-coefficient space) is a hypothesis, not a tested claim.
\item \textbf{No neural result.} The one neural study ended not resolvable; this paper makes no claim about trained models.
\end{itemize}
